## LineCallRecorder（com.steve.linecallrec）

LINE 通話錄音 Android App。

- 使用 Shizuku
- 偵測通話自動開始／停止錄音
- 自訂檔名

### 安裝

下載 [LineCallRecorder.apk](LineCallRecorder.apk)（或到 Releases 頁面下載），在手機上安裝。需先安裝並啟動 Shizuku。
